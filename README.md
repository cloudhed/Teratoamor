# Teratoamor

Teratoamor is an original 64-bit VST3 synthesizer built around pitched resonant filters excited by white noise, and is a spiritual attempt at mimicing a fraction of what Majken's Chimera did.

## Initial target

- Windows 64-bit
- VST3 instrument
- Standalone application
- MIDI-controlled polyphonic synthesis
- Three noise-driven resonators per voice
